# Видео с колодой: кадры — доказательство, окно кадра — факт

Статус: принято, 2026-10-10.

## Контекст

Видеорежим подставляет кадры в текст точнее, чем документный режим подставляет страницы колоды:
у кадра есть окно слайда, а у страницы колоды его нет, и привязку приходится восстанавливать по
речи. Когда у лекции есть и видео, и колода, можно взять лучшее из обоих.

Рассматривались варианты: вставлять кадры вместо страниц; вставлять и то и другое; отдавать
приоритет речи, а кадры учитывать как одно из доказательств наравне с остальными.

## Решение

- В конспект попадают только страницы колоды. Кадры, не совпавшие ни с одной страницей (доска,
  код, слайды вне колоды), отбрасываются.
- Совпадение кадра со страницей переносит окно кадра на страницу. Окно — факт и не оспаривается
  речью: доказательства по речи выбирают абзац только внутри окна.
- Страница, показанная несколько раз, получает одно место — окно с самыми сильными доказательствами.
- Страница, не найденная ни в одном кадре, привязывается как в документном режиме; окно сужается
  соседними страницами, найденными в кадрах.
- Сопоставление кадра со страницей сначала локальное (ключевые точки), визуальная модель —
  только для спорных случаев.

## Последствия

- Если лектор обсуждает слайд вне времени его показа, слайд встанет по времени показа, а не по речи.
- Качество колоды задаёт качество картинок в конспекте; кадры не подменяют плохие страницы.
- Ошибка сопоставления кадра со страницей переносит неверное окно, поэтому сопоставлению нужен
  порог уверенности, ниже которого окно не переносится.
