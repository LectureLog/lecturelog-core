# Глоссарий

## Слайды в конспекте

**Колода**
Приложенный пользователем документ со слайдами (PDF/PPTX). Одна колода на лекцию.
_Не путать:_ «презентация», «преза» — то же самое, канонично «колода».

**Страница колоды**
Один слайд колоды как изображение. Именно её картинка попадает в конспект, когда колода есть.

**Кадр**
Снимок видеоряда лекции с моментом, когда он был на экране. Может показывать страницу колоды,
слайд, которого в колоде нет, доску или код.

**Окно слайда**
Интервал записи, в течение которого слайд был на экране. Известно только для кадров; у страницы
колоды без видео окна нет.

**Каталог**
Описание каждого слайда, собранное моделью по его изображению: заголовок, пересказ видимого
текста, термины, роль.

**Привязка**
Решение, к какому разделу и к какому месту речи относится слайд. Опирается на доказательства.
_Не путать:_ с размещением — привязка может быть верной, а размещение всё равно уводить слайд в галерею.

**Размещение**
Решение, где слайд окажется в тексте конспекта: внутри абзаца, в галерее раздела или в приложении.

**Доказательство**
Наблюдение, подтверждающее привязку: совпадение речи с текстом слайда, явное упоминание,
визуальное совпадение кадра со страницей колоды, окно слайда.

**Уровень уверенности**
Оценка привязки: `verified`, `probable`, `unresolved`. От него зависит размещение.

**Неупомянутый слайд**
Слайд, у которого нет ни одного кандидата с доказательством, либо служебная пустая страница.
Идёт в приложение.

**Непривязанный слайд**
Слайд с кандидатом и доказательством, но с уверенностью ниже нужной для вставки в абзац. Идёт в
галерею раздела с самым сильным доказательством.
_Не путать:_ с неупомянутым — «не уверены, куда поставить» не значит «лектор не обсуждал».

**Галерея раздела**
Блок слайдов в конце раздела для слайдов, чья привязка к разделу есть, а к абзацу — недостаточно уверенная.

**Приложение**
Блок в конце конспекта для слайдов, которые лектор, по оценке системы, не обсуждал.

## Режимы

**Документный режим**
Аудио или видео плюс колода. Слайды берутся из колоды.

**Видеорежим**
Видео без колоды. Слайды берутся из кадров.

**Видео с колодой**
Видео плюс колода. В конспект идут только страницы колоды, а кадры служат доказательством того,
когда какая страница была на экране. Кадры, не совпавшие ни с одной страницей, в конспект не попадают.

## Оценка качества

**Прогон**
Одна обработка лекции конкретной версией системы с сохранёнными артефактами.

**Судья**
Отдельный агент, который вслепую оценивает конспект прогона по рубрике.

**Development / validation / holdout**
Наборы лекций. Development можно разбирать по слайдам; validation смотрят после этапа и не чинят
точечно; holdout открывают только перед решением о включении на проде.
